# Development priorities

Changes are selected through reproducible numerical examples and measured
application workloads. Each change proceeds through implementation, independent
correctness checks, benchmark comparison, artifact installation and review.

- Extend exact array operations with rational-oracle tests.
- Improve matrix kernels using complete factorization benchmarks.
- Add algebraic operations with exhaustive tests on finite carriers.
- Extend integration tests through installed packages and real PostgreSQL.
- Keep API signatures and executable examples synchronized with source.
