# Changelog

## [1.2.0]

### Added

- Optional C kernels for array summation, exact dot products and fused Gram entries.
- Contiguous column storage and scale handling for Jacobi SVD.
- Exact Decimal balance access in the ledger.
- Executable documentation examples and generated API signatures.

### Corrected

- Signed exponential evaluation, negative powers and division by small scalars.
- Numeric hash consistency and cancellation in ratio-based polynomial arithmetic.
- Closed finite cyclic arithmetic and modular prime-field operations.
- Stream term counts, batch-length validation and polynomial input ownership.
- Orthonormal completion of zero singular vectors.
- Pandas slicing, missing-value handling, concatenation and indexed selection.
- TNSIM API/service/database contracts, decimal serialization, cache persistence,
  executor cleanup and tensor gradient propagation.
- Benchmark entry points, rational references and package metadata.
