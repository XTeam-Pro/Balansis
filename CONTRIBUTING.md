# Contributing

Use a focused branch and submit a pull request to `master`. Follow the
[repository workflow](docs/GITHUB_REPOSITORY_STANDARD.md) and run the
[local checks](docs/development.md) for your change. Include a reproducible case
and an independent expected result for numerical changes.

Update generated API signatures and executable examples together with code.
Use synthetic test inputs. Preserve licensing notices and review the
[contributor agreement](CLA.md) before submitting contributions.
