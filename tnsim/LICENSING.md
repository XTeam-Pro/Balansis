# Balansis Licensing

Balansis uses a dual-licensing model:

- **Open-source route**: GNU Affero General Public License v3.0, full text in
  [LICENSE](LICENSE)
- **Commercial route**: proprietary commercial license, full baseline terms in
  [COMMERCIAL_LICENSE.md](COMMERCIAL_LICENSE.md)

## Which license applies

You must choose exactly one valid licensing route before using Balansis.

### Use the AGPL-3.0 route if

- you are willing to comply with AGPL-3.0 obligations;
- your distribution and deployment model is compatible with AGPL-3.0;
- you do not need proprietary commercial rights from the Licensor.

### Use the commercial route if

- you need to keep your source code private;
- you want to use Balansis in proprietary software;
- you want to embed Balansis into a paid product or service;
- you want to use Balansis in SaaS, managed service, OEM, white-label, or other
  commercial deployment models without AGPL-3.0 obligations;
- you need contractual support, maintenance, enterprise terms, or commercial
  scope grants.

## GitHub and package metadata

GitHub license detection works best when the repository root `LICENSE` file
contains one canonical OSI-approved license text. For that reason:

- the root [LICENSE](LICENSE) file contains the standard AGPL-3.0 text so
  GitHub can recognize the open-source license correctly;
- the commercial option is documented separately in
  [COMMERCIAL_LICENSE.md](COMMERCIAL_LICENSE.md);
- repository documentation, README badges, and package metadata state that the
  project is dual-licensed.

## Scope of the commercial document

The repository copy of [COMMERCIAL_LICENSE.md](COMMERCIAL_LICENSE.md) is the
standard baseline commercial license form. A binding commercial grant requires
an executed order, invoice, quote acceptance, or other written commercial
instrument issued or approved by the Licensor.

For operational convenience, the repository also includes
[ORDER_FORM_TEMPLATE.md](ORDER_FORM_TEMPLATE.md), which can be used as the
starting template for commercial orders and enterprise deals.
